# 더 플래티넘 AI 시연 키트

사내 아이디어 경진대회 제출용 시연 키트입니다. 휴대폰이나 PC 브라우저에서 바로 열립니다.

**바로 체험하기:** https://donghyun1park-web.github.io/platinum-ai-demo/

## 무엇을 볼 수 있나

| 화면 | 내용 |
|---|---|
| 모드 1 · 고객·조합원 체험 | 25년 차 84㎡ 거실을 4대 테마(북카페·호텔 스위트·에듀 패밀리·테라스 가든)로 바꿔 비포·애프터 비교, 3D 공간 걸어보기, 엔지니어 X-Ray(구조·배관·난방·환기·단열), 우리 집 사진 업로드 |
| 모드 2 · 심사위원 검증 대시보드 | Stage Gate 지표(예시), 8대 자동 검증 테스트 실행, 리드 인계 표, 테마 선호도, 역할 분담(RACI) |

- 5개 상태(현재 + 4대 테마)는 같은 벽·창호·천장 구조를 공유하는 실시간 3D 렌더입니다.
- **AI 실사 변환**은 본인의 Google Gemini API 키를 화면에 넣었을 때만 동작합니다. 키는 브라우저 메모리에만 있고 저장되거나 이 저장소로 전송되지 않으며, 새로고침하면 지워집니다.
- 대시보드의 KPI·리드 표는 **예시 데이터**입니다. 상담 신청 화면은 실제로 메시지를 보내지 않습니다.
- 화면의 이미지는 AI·3D로 연출한 예시이며 실제 시공·인허가 도면 및 마감재와 다를 수 있습니다.

권장 브라우저: 최신 크롬·엣지·사파리(WebGL 지원).

## 파일 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 배포용 단일 파일. 3D 엔진(Three.js)과 QR 라이브러리가 들어 있어 외부 CDN 없이 동작합니다. 직접 수정하지 말고 아래 빌드로 만듭니다. |
| `src/the_platinum_ai_simulator_v3.html` | 수정용 소스. Three.js를 CDN에서 불러옵니다(이 파일만 열어도 동작). |
| `tools/build_offline.py` | 소스 → `index.html` 빌드 스크립트. 라이브러리 버전을 고정하고 SHA-256으로 검증합니다. |
| `THIRD_PARTY_NOTICES.md` | 포함된 오픈소스 라이브러리의 라이선스 고지 |

## 수정 후 다시 배포하기

```bash
python tools/build_offline.py src/the_platinum_ai_simulator_v3.html index.html
git add -A && git commit -m "Update demo" && git push
```

푸시하면 1~2분 안에 같은 주소에 반영됩니다(보고서의 QR 코드는 그대로 유효).
